# AI Chatbot

A command-line chatbot built with Python and the OpenAI API.

## Technologies
- Python
- OpenAI API
- python-dotenv

## How to run
1. Clone the repo
2. Create a .env file with your OPENAI_API_KEY
3. Run: python chatbot.py
